Introdução
Visão geral da plataforma

O Whitelabel Loja Virtual é uma plataforma completa de e-commerce desenvolvida pela Sintetiza AI. Ela foi criada para que qualquer empresa possa ter uma loja virtual profissional, totalmente personalizada com sua identidade visual e integrada aos principais meios de pagamento do Brasil.

A plataforma inclui uma loja virtual para os clientes finais, um painel administrativo para gestão do negócio, suporte a múltiplos idiomas, importação em massa de produtos, cupons de desconto, e muito mais.

Opção 1: VPS Ubuntu (recomendado)

A maneira mais simples de instalar em um servidor Ubuntu. Dois scripts cuidam de tudo: instalação de dependências e configuração interativa da aplicação.

1
Clone o repositório no servidor
Conecte via SSH e clone o projeto para o diretório desejado:
git clone https://github.com/sua-org/whitelabel-loja-virtual.git /var/www/loja
cd /var/www/loja
2
Execute o script de instalação de dependências
Instala Node.js 20, PostgreSQL 16, Nginx, PM2 e Certbot. É idempotente — seguro executar mais de uma vez.
chmod +x setup/*.sh
sudo bash setup/install.sh
3
Execute o script de configuração interativa
Configura banco de dados, gera .env com JWT automático, compila a aplicação, inicia com PM2 e configura Nginx.
bash setup/setup.sh
O script pedirá: nome/usuário/senha do banco, porta da aplicação, credenciais SMTP, domínio do site e se deseja configurar HTTPS via Let's Encrypt.

Opção 2: Docker Compose

Ideal para ambientes containerizados. Sobe a aplicação e o PostgreSQL juntos, com banco já inicializado pelas migrações.

1
Crie o arquivo de variáveis de ambiente
Copie o exemplo e edite com suas configurações reais:
cp setup/.env.example .env
nano .env
2
Suba os containers
cd setup
docker compose up -d
3
Verifique os logs
docker compose logs -f app

Opção 3: Railway / Render / Heroku

1
Conecte o repositório à plataforma
Importe o repositório GitHub na plataforma PaaS escolhida e adicione um banco de dados PostgreSQL.
2
Configure as variáveis de ambiente
Adicione todas as variáveis da tabela abaixo no painel da plataforma, especialmente DATABASE_URL, JWT_SECRET e as configurações SMTP.
3
Configure o build e o start
Comando de build: npm run build — Comando de start: node dist/index.cjs

Configuração SMTP para MFA

A plataforma usa MFA por e-mail para proteger o acesso ao painel administrativo. A cada login, um código OTP é enviado para o e-mail do administrador.

Para Gmail: acesse myaccount.google.com → Segurança → Senhas de app, gere uma senha de 16 caracteres e use-a como SMTP_PASS. Não use sua senha principal do Google.

# Exemplo para Gmail com Senha de App
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=seuemail@gmail.com
SMTP_PASS=xxxx xxxx xxxx xxxx

Segurança

Boas práticas importantes:
  • Nunca versione o arquivo .env — ele já está no .gitignore
  • Defina SETUP_SECRET para proteger a rota de criação do primeiro admin
  • Use HTTPS em produção — o install.sh inclui o Certbot (Let's Encrypt)
  • O rate limiting está ativo nas rotas de autenticação por padrão

Atualizar para nova versão

Em servidores VPS, use o script de atualização que faz pull, reinstala dependências, roda migrações e reinicia o PM2:

bash /var/www/loja/setup/update.sh

Primeiro Acesso
Configuração inicial da conta de administrador

Na primeira vez que a plataforma é iniciada, não existe nenhum administrador cadastrado. É preciso criar a conta inicial antes de usar o painel.

📸 [Screenshot: Tela de Login com link "Primeiro Acesso"]
1
Acesse o painel administrativo
Abra o navegador e vá para http://localhost:5003/admin. Você será redirecionado automaticamente para a tela de login.
2
Clique em "Primeiro Acesso"
Na tela de login, localize e clique no link "Primeiro Acesso" exibido abaixo do formulário.
3
Preencha os dados do administrador
Informe o e-mail e a senha que serão usados para acessar o painel. Use uma senha forte com pelo menos 8 caracteres.
4
Clique em "Criar conta de administrador"
Após o cadastro ser criado, você será redirecionado para a tela de login.
5
Faça login com as credenciais criadas
Informe o e-mail e a senha cadastrados e clique em "Entrar". Você será levado ao Dashboard.
Atenção: Após o primeiro administrador ser criado, o link "Primeiro Acesso" é desativado por segurança e não poderá ser usado novamente.

Produtos
Gestão completa do catálogo de produtos

A seção de Produtos é onde você cadastra e gerencia todo o catálogo da sua loja. Cada produto pode ter fotos, variantes (como tamanho e cor), preço promocional, controle de estoque e categorias.

📸 [Screenshot: Listagem de Produtos no painel admin]

Como adicionar um novo produto

1
Acesse Admin → Produtos
No menu lateral, clique em Produtos.
2
Clique em "Novo Produto"
O botão fica no canto superior direito da listagem.
3
Preencha as informações básicas
Nome do produto, slug (URL amigável gerado automaticamente), descrição, preço e preço promocional (opcional).
4
Configure estoque e categoria
Informe a quantidade em estoque e selecione a categoria. Ambos são opcionais mas recomendados.
5
Faça upload das fotos
Arraste ou selecione uma ou mais imagens. A primeira foto será a foto principal do produto. Formatos aceitos: JPG, PNG, WebP.
6
Crie variantes (opcional)
Na aba de variantes, adicione combinações como Tamanho (P, M, G) ou Cor (Azul, Vermelho). Cada variante pode ter estoque e preço próprios.
7
Publique o produto
Ative o toggle "Publicado" para que o produto apareça na loja. Produtos não publicados ficam ocultos dos clientes.
8
Clique em "Salvar"
O produto será salvo e aparecerá imediatamente na loja se estiver publicado.
Dica: O slug é a URL do produto na loja (ex.: /loja/produto/camiseta-azul). Ele é gerado automaticamente a partir do nome, mas pode ser editado manualmente.

Categorias
Organização do catálogo por categorias

As categorias organizam os produtos da loja e permitem que os clientes filtrem facilmente o que procuram. Uma categoria pode ser associada a vários produtos.

1
Acesse Admin → Categorias
No menu lateral, clique em Categorias.
2
Clique em "Nova Categoria"
Abre o formulário de criação de categoria.
3
Informe o nome e o slug
O slug é a identificação da categoria na URL. Exemplo: camisetas, calcados.
4
Salve a categoria
A categoria estará disponível para seleção ao criar ou editar produtos.
Atenção: Ao excluir uma categoria, os produtos vinculados a ela não são excluídos — eles apenas perdem a associação com a categoria.

Pedidos
Visualização e atualização de status dos pedidos

A seção de Pedidos exibe todos os pedidos realizados pelos clientes, com detalhes de itens, valores, endereço de entrega e histórico de status.

📸 [Screenshot: Listagem de Pedidos com filtros de status]

1
Acesse Admin → Pedidos
Veja a lista de todos os pedidos ordenados por data.
2
Clique no número do pedido
Abre a página de detalhe com itens, valores, dados do cliente e histórico de status.
3
Atualize o status
Selecione o novo status no seletor e clique em "Atualizar". O cliente receberá um e-mail automático (se SMTP configurado).
4
Informe o código de rastreio (para "Enviado")
Preencha o código de rastreio e a transportadora. Essas informações aparecem para o cliente na página do pedido.

Clientes
Visualização da base de clientes

A seção de Clientes exibe todos os usuários que realizaram pelo menos um pedido na loja. É possível visualizar o histórico de compras de cada cliente.

1
Acesse Admin → Clientes
Veja a lista de todos os clientes com nome, e-mail, telefone e total de pedidos.
2
Clique em um cliente para ver detalhes
Visualize o histórico completo de pedidos do cliente selecionado.
Nota: O cadastro de clientes é somente leitura. Os clientes são registrados automaticamente ao realizar o primeiro pedido.

Cupons
Criação e gestão de cupons de desconto

Os cupons de desconto permitem criar promoções para atrair e fidelizar clientes. Os cupons são aplicados pelo cliente no carrinho de compras antes de finalizar o pedido.

Tipos de cupom

TipoEfeitoExemplo
PercentualDesconto em % sobre o total10% de desconto
Valor fixoDesconto em R$ sobre o totalR$ 20,00 de desconto
Frete grátisZera o valor do freteFrete grátis
1
Acesse Admin → Cupons
2
Clique em "Novo Cupom"
3
Defina o código do cupom
O código é o que o cliente digita no carrinho. Ex.: PROMO10, VERAO20. Use letras maiúsculas e sem espaços.
4
Selecione o tipo e informe o valor
Para percentual: informe o número (ex.: 10 para 10%). Para valor fixo: informe o valor em reais (ex.: 25 para R$ 25).
5
Configure a validade e limite de usos (opcional)
Defina uma data de expiração e/ou um número máximo de utilizações. Deixe em branco para ilimitado.
6
Ative e salve
Marque o cupom como "Ativo" e clique em "Salvar".

Importação em Massa
Cadastro de produtos via CSV ou XLSX

A importação em massa permite cadastrar ou atualizar centenas de produtos de uma só vez usando uma planilha. É ideal para migrar um catálogo existente ou fazer atualizações em lote.

Colunas do template

ColunaObrigatórioDescrição
nomeSimNome do produto
slugSimURL amigável única
descricaoNãoDescrição detalhada
precoSimPreço em reais (ex.: 49.90)
preco_promocionalNãoPreço com desconto
estoqueNãoQuantidade em estoque
categoriaNãoSlug da categoria
publicadoNãotrue ou false
1
Acesse Admin → Importar
2
Baixe o template
Clique em "Baixar template" para obter a planilha modelo no formato correto.
3
Preencha os dados
Abra a planilha no Excel ou Google Sheets e preencha cada produto em uma linha, seguindo as colunas do template.
4
Faça o upload do arquivo
Salve como .csv ou .xlsx e arraste para a área de upload na página de importação.
5
Revise a pré-visualização e importe
Confira os dados exibidos na pré-visualização e clique em "Importar" para processar.
Comportamento de atualização: Produtos com o mesmo slug são atualizados. Produtos com slugs novos são criados. Nenhum produto é excluído na importação.

Configurações
Personalização completa da loja

A seção de Configurações centraliza todas as personalizações da plataforma: identidade visual, integrações de pagamento, e-mail e frete.

Informações da Loja

Configure o nome da loja, descrição, CNPJ, endereço, telefone e e-mail de contato. Essas informações aparecem no rodapé da loja e nos e-mails enviados aos clientes.

Aparência

Escolha uma paleta de cores predefinida ou defina cores personalizadas para a loja. As mudanças são aplicadas em tempo real.

📸 [Screenshot: Seletor de cores e paletas no painel de Configurações]

Pagamento (MercadoPago)

Informe o Access Token do MercadoPago para habilitar os meios de pagamento na loja. Obtenha suas credenciais em mercadopago.com.br/developers.

Configuração do .env

# Banco de dados PostgreSQL
DATABASE_URL=postgresql://usuario:senha@localhost:5432/whitelabel

# Segurança
JWT_SECRET=sua_chave_secreta_muito_longa_e_aleatoria

# Servidor
PORT=5003

# E-mail (SMTP)
SMTP_HOST=smtp.seuprovedor.com
SMTP_PORT=587
SMTP_USER=seu@email.com
SMTP_PASS=sua_senha_smtp
CONTACT_EMAIL=contato@sualoja.com

# MercadoPago (opcional)
MERCADO_PAGO_TOKEN=APP_USR-xxxxxxxxxxxxxxxxxxxx

Meio de PagamentoDetalhesPrazo
💠 PIX Desconto de 5% aplicado automaticamente Instantâneo
📄 Boleto Bancário Sem desconto adicional 3 dias úteis para compensação
